# LeadRadar — Дашборд аналитики лидов Битрикс24

## Цель
Full-stack приложение для визуальной аналитики лидов из Битрикс24 с 15 метриками и интерактивными графиками.

## Стек технологий
- **Backend:** Node.js 20 + Express + SQLite (better-sqlite3)
- **Frontend:** React 18 + Vite + Recharts + TailwindCSS
- **Sync:** Bitrix24 REST API (webhook URL) с инкрементальной синхронизацией
- **Deploy:** VibeCode Deploy API (runtime: node20)

## База данных (SQLite)

### Таблица `leads`
```sql
CREATE TABLE leads (
    id INTEGER PRIMARY KEY,
    bitrix_id INTEGER UNIQUE,           -- ID лида в Битрикс24
    title TEXT,
    status_id TEXT,                     -- NEW, IN_PROGRESS, SUCCESS, CANCELLED
    opportunity REAL,
    currency_id TEXT,
    assigned_by_id INTEGER,
    created_by_id INTEGER,
    source_id INTEGER,
    contact_id INTEGER,
    company_id INTEGER,
    utm_source TEXT,
    utm_medium TEXT,
    utm_campaign TEXT,
    utm_content TEXT,
    utm_term TEXT,
    date_create TEXT,                   -- datetime
    date_modify TEXT,                   -- datetime
    date_closed TEXT,                   -- datetime (when SUCCESS/CANCELLED)
    synced_at TEXT                      -- когда синхронизировано
);

CREATE INDEX idx_status ON leads(status_id);
CREATE INDEX idx_date_create ON leads(date_create);
CREATE INDEX idx_assigned_by ON leads(assigned_by_id);
CREATE INDEX idx_source ON leads(source_id);
```

### Таблица `sync_log`
```sql
CREATE TABLE sync_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    sync_type TEXT,                     -- full / incremental
    started_at TEXT,
    finished_at TEXT,
    leads_synced INTEGER,
    status TEXT                         -- success / error
);
```

## Синхронизация с Битрикс24

### Подключение
- Используем **Webhook URL** (проще для фоновой синхронизации)
- Формат: `https://{portal}.bitrix24.ru/rest/1/{webhook_token}/crm.lead.list`

### Стратегия синхронизации
1. **Первый запуск** — полный сбор всех лидов (pagination, limit=50)
2. **Последующие** — инкрементальная синхронизация (`>DATE_MODIFY`)
3. **Расписание** — каждые 15 минут (node-cron)
4. **Rate limiting** — 0.2s между запросами (лимит ~2 req/sec)

### Bitrix24 API
- `crm.lead.list` — получить лиды с фильтрацией
- `crm.lead.get` — получить детали одного лида
- Статусы: NEW, IN_PROGRESS, SUCCESS, CANCELLED
- Поля: ID, TITLE, STATUS_ID, OPPORTUNITY, CURRENCY_ID, ASSIGNED_BY_ID, SOURCE_ID, UTM-метки, DATE_CREATE, DATE_MODIFY, DATE_CLOSED
